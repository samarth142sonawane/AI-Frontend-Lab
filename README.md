# AI Frontend Lab

This workspace contains three frontend projects built to demonstrate modern HTML, CSS, and JavaScript design patterns.

## Projects

- `AI-Student-Dashboard` — A student dashboard interface with charts, cards, and quick access to academic information.
- `Cricket-Analytics-Website` — A responsive landing page for cricket analytics with data highlights and visual presentation.
- `Space-Exploration-Website` — A space-themed website focused on exploration, imagery, and mission details.

## Structure

Each project folder contains its own `index.html`, styles, and scripts. Open the relevant folder and launch the HTML file in a browser to review the project.

## Notes

- The repository is organized for frontend learning and showcase purposes.
- No additional build tools are required; these are static web pages.
- Use a modern browser for the best presentation.
