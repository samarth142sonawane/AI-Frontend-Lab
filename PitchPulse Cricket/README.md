# PitchPulse Cricket Analytics

PitchPulse Cricket Analytics is a cricket-focused website built using HTML, CSS, and JavaScript.

I created this project as part of my frontend development journey to practice building larger websites instead of small individual components. The idea was to design a platform where users can view cricket scores, news, league information, ongoing series, player rankings, and cricket analytics in one place.

---

## Features

### Home

- Hero section with featured player
- Cricket analytics themed landing page
- Modern navigation bar

### Live Scores

- Live match score cards
- Match status information

### Cricket News

- News cards with headlines and summaries
- Responsive layout

### Leagues

International leagues:

- IPL
- BBL
- PSL
- The Hundred
- WPL

Domestic tournaments:

- Ranji Trophy
- Duleep Trophy
- Syed Mushtaq Ali Trophy

### Series

- T20
- ODI
- Test

Users can switch between formats to view different ongoing series.

### Player Statistics

- ICC rankings
- Batting rankings
- Bowling rankings

### Analytics Section

- Total matches analyzed
- Video clips processed
- Player statistics stored
