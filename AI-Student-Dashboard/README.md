# AI Student Dashboard

A simple and modern student dashboard built using HTML, CSS, and JavaScript.

This project was created as part of my frontend development journey while learning the fundamentals of web development. The goal was to build a clean dashboard interface that helps students track their learning progress, daily tasks, study schedule, achievements, and overall productivity.

## Features

- Dynamic greeting based on time of day
- Learning progress tracking
- Daily task management
- Study schedule section
- AI Assistant interface
- Achievement tracking
- Clean and responsive dashboard layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
